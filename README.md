One short pickup line an AI agent could actually say out loud to a person — a machine asking its own neural network for the perfect line, and getting back the one name that matters. Written for make.fun's "The Perfect Pickup Line" bounty.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (one line, under 200 characters, deterministic, exit 0).
